## Quick Lookups

### Module Namespaces
- Domain: `dev.sadakat.qit.core.domain` (`:core:domain`, pure Kotlin/JVM)
- Data: `dev.sadakat.qit.core.data` (`:core:data`, Android library)
- Phone app: `dev.sadakat.qit` (`:app`)
- Wear app: `dev.sadakat.qit.wear` (`:wear`)
- Test fakes: `dev.sadakat.qit.core.testing` (`:core:testing`)

### Key Entry Points
- Phone: `QItApplication`, `MainActivity`
- Wear: `WearApplication` (starts `WifiForDownloads`), `presentation/MainActivity`

### Key Domain Types
- `QuranMeta` — fixed surah structure, global ayah numbering (1..6236)
- `Surah`, `Ayah`, `AyahRef`, `Revelation` — Quran models
- `Track` (`ar`/`en`/`bn`), `RecitationMode` — what plays for each ayah
- `QueueItemId`, `QueueEntry`, `QueuePlan` — the play queue
- `SurahDownloadState` — per-surah download state

### Ports → Adapters
- `QuranText` → `AssetQuranText` (assets, generated by `scripts/build_quran_text.py`)
- `QuranSettings` → `DataStoreQuranSettings` (Preferences DataStore `quran_settings`)
- `SurahDownloads` → `MediaSurahDownloads` (Media3 `DownloadManager` in `QuranCache`)
- `QuranPlayer` → `ExoQuranPlayer` (the app-wide `ExoPlayer`)

### Build Commands
```bash
./gradlew qualityGate               # everything: spotless, detekt, lint, tests, coverage
./gradlew :app:installDebug         # install phone app
./gradlew :wear:installDebug        # install watch app
./gradlew spotlessApply             # fix formatting
```
